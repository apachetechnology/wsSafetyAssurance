G1: Ensure the ACAS Xu system is secure against threats and resilient in operation.
G1.1: Security Architecture Adequacy. Establish that the security architecture of ACAS Xu is sufficient for intended operation.
G1.2: Resilience Against External Threats. Demonstrate resistance and recovery from cyberphysical attacks.
G1.3: Data Integrity Verification. Ensure integrity and authenticity of data used and generated by ACAS Xu.
G1.4: Compliance with Aviation Cybersecurity Guidelines. Prove compliance with national and international cybersecurity guidelines for avionics systems.
G1.5: Continuous Security Monitoring. Maintain continuous monitoring and update defenses in response to emerging threats.
G1.6: User Training and Awareness. Ensure that all relevant personnel are trained on the use and security features of ACAS Xu.
S1: Divide security verification into system security architecture, external threats, and data integrity.
S1.1: Analyze each component for potential vulnerabilities and mitigation strategies.
S1.2: Evaluation of system response under simulated attack scenarios.
S1.3: Validate mechanisms for data protection and error checking.
S1.4: Crossreference system security features against compliance checklists.
S1.5: Establish protocols for continuous security assessment and updates.
S1.6: Develop and implement a comprehensive security training program.
