# wsSafetyAssurance

# Automatic Instantiation of Assurance Cases from Patterns Using Large Language Models
  https://figshare.com/articles/dataset/Automatic_Instantiation_of_Assurance_Cases_from_Patterns_Using_Large_Language_Models/27103225/2

## Overview
This repository contains all the resources used for the research on automatically generating assurance cases from patterns using large language models (LLMs).

## Repository Structure

### Dataset
- **Description:** Contains the GSN (Goal Structuring Notation) images for the assurance case patterns and the corresponding assurance cases derived from these patterns for each system in our dataset.

### Experiment Without S.E Knowledge
- **Description:** Contains all the system prompts, user prompts, Python scripts, and results obtained from experiments without incorporating software engineering knowledge.
- **Structure:** Information is organized by large language model and further segmented by each system in our dataset.

### Experiment With S.E Knowledge
- **Description:** Contains all the system prompts, user prompts, Python scripts, and results obtained from experiments that include software engineering knowledge (i.e., Experiments 2 to 9).
- **Structure:** Information is organized by large language model and further categorized by each system in our dataset.

### Varying One-Shot Example Experiments
- **Description:** Contains all the system prompts, user prompts, Python scripts, and results obtained when varying the assurance case pattern and the assurance case derived from this pattern in our one-shot examples.

- **Structure:** Information is organized by large language model and further categorized by each system as a one-shot example.
